## 2. テスト方針

### 単体テスト（Swift Testing / Jest）

必ず書くもの（Swift と TypeScript の両方で同じケース）：

| 対象 | ケース |
|---|---|
| 重み・確率（F-21） | いいね [4,3,3,2,2,1,1,0] → 表示% [16,15,15,13,13,11,11,5]／みんな平等で全候補が同じ％／候補1件で100% |
| レベル（F-22） | 比 1.2 ちょうどで「出やすい」、0.85 ちょうどで「ふつう」、0.84 で「レア」 |
| 人気（F-23） | 5人ルーム：いいね2→なし、3→みんな推し、4→全員いいね／2人ルーム（n'=1）：いいね1でもリボンなし |
| 解禁（F-31） | 全員OK：4/5→未、5/5→解禁／過半数：2/4→未、3/4→解禁、3/5→解禁／締切：前後1秒／強制解禁はOK数に関係なく解禁 |
| 抽選（F-40） | 固定シードで同じ結果／1万回試行の当選率が理論値±2%／除外リストの候補は当選しない |
| 経過時間（F-12） | 59秒「たった今」、1分「1分前」、23時間「23時間前」、前日「昨日」、6日「6日前」、7日「M/D」 |
| 招待コード | 6文字、使用文字に `0 O 1 I` を含まない、表示は `ABC-123` |

### Functions・ルールのテスト（Firebase Emulator）

- セキュリティルール：メンバー以外は読めない／自分の投稿にいいねできない／他人の `likedBy` を消せない／`ready` は自分の分だけ変更できる
- `drawGacha` を2つ同時に呼んでも抽選記録が1件
- `joinRoom` で21人目が拒否される
- `addCandidate` で上限・重複・状態のチェック

### UI テスト（XCUITest、Emulator に接続）

1. 作成 → 招待コードで2人目が参加 → 候補3件投稿 → いいね → 全員準備OK → ガチャ → 結果 → 決定 → ホームの「思い出のきっぷ」に表示
2. 引き直し：可決 → 前回の当選が対象外になって再抽選
3. 次のルームで「過去のアイデア」から持ち込み
