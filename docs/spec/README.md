# ドコガチャ 開発資料

友人グループで「行きたい場所」を持ち寄り、ガチャで行き先を決める iOS アプリ **ドコガチャ** の企画・仕様・デザイン資料です。
この資料だけで実装に着手できることを目標にしています。

- アプリ名：**ドコガチャ**
- App Store サブタイトル：**友達旅行・おでかけの行き先ガチャ**
- キャッチコピー（仮）：みんなの「行きたい」で回すガチャ
- 対象：iOS（iPhone）のみ。Android は将来検討
- Bundle ID：`jp.shilokuma.Dokogacha`

| パス | 内容 |

プロトタイプの HTML は専用ランタイム上で動く形式なので、そのままブラウザで開いても表示されません。**レイアウト・色・寸法・文言・挙動の正解を確認するための参照資料**として読んでください。
実際の画面はオーナーの Claude キャンバスで確認できます（共有が必要）：https://claude.ai/artifact/29zMMSKAiz4zmczm74BKyN

## 実装担当 AI への前提

1. 仕様の優先順位は **02_requirements.md ＞ 03_screens.md ＞ プロトタイプ** です。食い違いがあれば上位に従ってください。
2. リポジトリは iOS アプリのテンプレートから作られています（Xcode プロジェクト、xcconfig、SwiftLint、CI が用意済み）。ビルド・ブランチ運用・PR の書き方はリポジトリ直下の `README.md` に従ってください。
3. 「仮決め」と書かれた項目は、オーナーに確認せず仮決めの内容で実装して構いません。[06 の未決事項](06_implementation_plan.md#未決事項仮決め) にまとめてあります。
4. プロトタイプにある「（モック）」「デモ用の自動OK」などの演出は実装しません（02 の各章に本番の挙動を書いています）。
5. ユーザーに見える文言は日本語です。文言は 03_screens.md の表記に合わせてください。

- 見た目は 04_design_system.md と design/tokens.json の値だけを使い、design/prototype/Main.dc.html と見比べて合わせてください。
